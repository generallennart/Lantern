Lantern aktualisieren

Diese Seite kann auftauchen, weil Lantern eine neuere offizielle Version auf GitHub gefunden hat.

Warum ist das sicher? Lantern fragt nur die oeffentliche Versionsnummer des offiziellen Projekts ab. Es werden keine Chats, Texte, Konten, Kennungen oder Passwoerter uebertragen. GitHub sieht dabei nur normale technische Verbindungsdaten wie bei jedem Webseitenaufruf, zum Beispiel deine IP-Adresse. Diese Seite und die Dateien kommen nur aus dem Ordner, den du selbst eingerichtet hast.

Wenn du Lantern mit Git eingerichtet hast

  1. Oeffne deinen Lantern-Ordner in Dokumente.
  2. Mache einen Doppelklick auf AKTUALISIEREN.cmd.
  3. Wenn Chrome aufgeht, suche Lantern auf chrome://extensions und klicke auf den Kreis-Pfeil zum Neu laden.
  4. Lade offene ChatGPT-, Claude- oder Gemini-Seiten einmal mit F5 neu.

Das Skript prüft zuerst die genaue offizielle Adresse https://github.com/generallennart/Lantern.git, den freigegebenen Hauptzweig und eigene Änderungen. Erst dann verwendet es git pull --ff-only. Eigene Änderungen werden nicht zusammengeführt oder überschrieben.

Wenn du Git noch nicht eingerichtet hast

  1. Oeffne den Ordner, aus dem du Lantern gerade installiert hast.
  2. Mache einen Doppelklick auf INSTALLIEREN-MIT-AKTUALISIERUNGEN.cmd.
  3. Falls Git fehlt, oeffnet sich nur die offizielle Git-Downloadseite. Installiere Git mit den Voreinstellungen und starte die Datei danach noch einmal.
  4. Die Datei legt Lantern in Dokumente ab, oeffnet die große Lantern-Anleitung und chrome://extensions.
  5. In Chrome Entwicklermodus einschalten, auf Entpackte Erweiterung laden klicken und genau diesen Ordner auswählen: Dokumente\Lantern\lantern.

Du brauchst dafuer kein GitHub-Konto und kein Passwort. Auf einem verwalteten Arbeitsrechner kann die Git-Installation durch die IT gesperrt sein; dann bleib beim ZIP-Weg oder frage die IT.

Wenn du lieber bei ZIP-Dateien bleibst

  1. Klicke im Lantern-Menue auf Release ansehen.
  2. Lade die neue ZIP-Datei herunter und entpacke sie.
  3. Ersetze nur den alten lantern-Ordner durch den neuen.
  4. Oeffne chrome://extensions, klicke bei Lantern auf Neu laden und druecke auf offenen Chat-Seiten F5.
Vollautomatisch geht es erst mit dem Chrome Web Store. Chrome aktualisiert Erweiterungen aus dem Store selbst. Eine lokal geladene Erweiterung darf sich aus Sicherheitsgruenden nicht selbst ersetzen. Bis dahin ist der Doppelklick auf AKTUALISIEREN.cmd der kuerzeste sichere Weg.
English

This page appears only because Lantern found a newer public version in its official GitHub project. It checks only the version number; no chats, text, accounts, identifiers, or passwords are sent. GitHub sees normal technical connection data, such as an IP address, as with any web request.

Git setup: In your Lantern folder, double-click AKTUALISIEREN.cmd. It verifies the official remote, released main branch, and clean worktree before updating. Then reload Lantern on chrome://extensions and reload open chat pages.

First-time Git setup: Double-click INSTALLIEREN-MIT-AKTUALISIERUNGEN.cmd. It clones only the public official repository into Documents, opens the main guide and chrome://extensions, then you load Documents\Lantern\lantern. No GitHub account or password is needed. On a managed work device, IT may block Git installation; use the ZIP path or ask IT in that case.

Why not fully automatic? Chrome allows automatic extension updates only through the Chrome Web Store. A locally loaded extension must not replace itself.
